# Harness Desktop Shell

**Неофициально.** Нативное окно для веб-интерфейса [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).
Не связано с DeepSeek и не поддерживается ими.

> **Написано ИИ.** Код, документация и история коммитов в этом репозитории созданы
> ИИ-агентом (DeepSeek Harness) по постановке автора и просмотрены автором. Здесь нет кода
> DeepSeek, и проект не говорит от имени компании.

Оболочка не содержит сам harness: она запускает **установленный** `dsh`
(`dsh web --no-open`), читает из его вывода адрес с токеном и открывает его в окне
Electron. Используется ваш обычный профиль `web` — сессии, плагины, модели и настройки
остаются прежними.

## Зачем

- нет панели браузера и расширений;
- нет системного прокси и вмешательства расширений — у Electron своя сессия;
- отдельные куки и хранилище от повседневного браузера;
- микрофон разрешён только для origin harness;
- одно окно, один экземпляр, масштаб по Ctrl.

## Требования

- Linux x64 (собрано на Arch/EndeavourOS; подойдёт любой дистрибутив с glibc);
- установленный `dsh` в `PATH` (`npm i -g @deepseek-ai/dsh`) или свежая запись в `~/.npm/_npx/*`;
- `libfuse2` для AppImage (иначе `--appimage-extract-and-run`).

## Установка

Скачайте `DeepSeekHarness-<version>.AppImage` из [Releases](../../releases):

```bash
chmod +x DeepSeekHarness-*.AppImage
./DeepSeekHarness-*.AppImage
```

Сначала остановите `dsh web`, запущенный в терминале: оболочка занимает порт `3080` и не
стартует, пока он занят — два хоста не должны делить один профиль.

## Использование

| Клавиши | Действие |
| --- | --- |
| `Ctrl+=` / `Ctrl+Shift+=` (цифровой `+`) | крупнее |
| `Ctrl+-` | мельче |
| `Ctrl+0` | сбросить масштаб |

Масштаб сохраняется между запусками. Закрытие окна завершает приложение и запущенный им хост.

### Переменные

- `DSH_DESKTOP_BIN` — путь к `…/@deepseek-ai/dsh/lib/bin.js` (или лаунчеру `dsh`);
- `DSH_DESKTOP_NODE` — Node для запуска CLI (по умолчанию `node` из `PATH`, затем
  собственный Node из Electron).

## Как это работает

1. Проверяет, что порт 3080 свободен.
2. Находит CLI (`DSH_DESKTOP_BIN` → `PATH` → свежий кэш npx) и запускает
   `dsh web --host 127.0.0.1 --port 3080 --no-open`.
3. Ждёт в stdout строку `dsh web: http://…?token=…`.
4. Загружает этот адрес в `BrowserWindow`; токен выставляет cookie сессии.
5. Разрешает микрофон только для origin harness.
6. При выходе отправляет дочернему хосту `SIGTERM` (затем `SIGKILL` через 4 с).

Релизы собираются GitHub Actions на каждый тег `v*`.
