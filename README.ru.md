# Harness Desktop Shell

**Неофициальная** нативная оболочка для веб-интерфейса [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).
Не связана с DeepSeek и не поддерживается ими.

Оболочка не содержит сам harness: она запускает **установленный** `dsh` (`dsh web --no-open`),
читает из его вывода адрес с токеном и открывает его в окне Electron. Используется ваш обычный
профиль `web` — сессии, плагины, модели и настройки остаются прежними.

## Зачем

- нет панели браузера и расширений;
- нет системного прокси и вмешательства расширений — у Electron своя сессия;
- отдельные куки и хранилище от повседневного браузера;
- микрофон разрешён только для origin harness;
- одно окно, один экземпляр, масштаб по Ctrl.

## Требования

- Linux x64 (проверено на Arch/EndeavourOS; подойдёт любой дистрибутив с glibc);
- установленный `dsh` в `PATH` (`npm i -g @deepseek-ai/dsh`) или свежая запись в `~/.npm/_npx/*`;
- `libfuse2` для AppImage (иначе `--appimage-extract-and-run`).

## Запуск

Скачайте `DeepSeekHarness-<version>.AppImage` из [Releases](../../releases):

```bash
chmod +x DeepSeekHarness-*.AppImage
./DeepSeekHarness-*.AppImage
```

Сначала остановите `dsh web`, запущенный в терминале: оболочка занимает порт `3080`
и не стартует, пока он занят.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+=` / `Ctrl+Shift+=` | крупнее |
| `Ctrl+-` | мельче |
| `Ctrl+0` | сбросить масштаб |

Масштаб сохраняется между запусками. Закрытие окна завершает приложение и запущенный им хост.

## Сборка

```bash
npm ci
npx electron-builder --linux AppImage
```

Результат — в `dist/`. На CI тег `v*` собирает AppImage и прикрепляет его к релизу.
